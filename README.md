# NAAAntoka

全国学力・学習状況調査（NAAA）の変数を探し、年度間で共通の変数を使った分析用データを作成するパッケージです。

**CSVのUTF-8変換 → 分析で使う変数一覧のxlsx出力 → Excelで分析で使う変数を選択 → 年度間の縦結合**が可能です。
異なる年度のデータから分析に使いたい変数候補をまとめて抽出し、対応表の`concept_id`・`concept`を確認・編集した後に、その対応関係に沿ってデータを読み込みます。
質問文や選択肢の違いを確認し、どの変数を同じ項目として扱うかは分析者が決めることができます。
ロング型のメタデータ（xlsx形式）に対応しています。メタデータのファイル名は任意です。

## 主な関数

| 関数 | 役割 |
|---|---|
| `set_naaa_metadata()` | メタデータのxlsxファイル、またはそのフォルダを指定 |
| `convert_utf8()` | 指定CSVをUTF-8へ変換し、別フォルダへ保存 |
| `make_variable_mapping()` | 調査カテゴリ・年度・変数で候補を抽出し、対応表をxlsxで保存 |
| `read_naaa_data()` | 編集済みの対応表（xlsx）に基づいて必要な列を読み込み、年度間で縦結合 |
| `add_naaa_variables()` | 作成済みデータの元CSV内の行対応を保ち、別の対応表から列を追加 |
| `search_naaa_variables()` | キーワードで変数名・質問文・ラベルを検索 |

## インストールと読み込み

以下の方法でインストールしてください。

```r
install.packages("remotes")
remotes::install_github("Lanlanbow/NAAAntoka")

library(NAAAntoka)
```

実データは同梱していません。CSVは、ご自身の環境にあるファイルを指定してください。
パッケージの処理はローカルで完結します。インストール後は、変換・検索・データ作成をオフラインで利用できます。

### ファイルの配置例

分析環境に、元のCSVとxlsx形式のメタデータを配置します。

```text
分析用フォルダ/
├─ raw/
│  └─ H24_児童.csv
└─ meta/
   └─ metadata_long.xlsx
```

`raw`と`meta`は必要に応じて用意し、`raw`には利用する実CSV、`meta`にはメタデータのxlsxファイルを置きます。
以降の相対パスの例は、この分析用フォルダを作業フォルダとして説明します。
現在の作業フォルダは`getwd()`で確認してください。

### メタデータの場所を指定する

メタデータのxlsxファイルが1つ入ったフォルダを指定します。ファイル名は任意です。

```r
set_naaa_metadata("meta")
```

同じフォルダにxlsxが複数ある場合は、ファイルを直接指定してください。
Excelの作業用ファイル（`~$`で始まるもの）は選択対象から除きます。

```r
set_naaa_metadata("meta/metadata_long.xlsx")
```

メタデータが1シートだけならシート名は任意です。複数シートがある場合は、メタデータを`metadata`シートに入れてください。
1行目を列名として読みます。`01`などのコード列名は、Excel上でも文字列として保存してください。

一度読み込んだメタデータはRセッション内で再利用します。
検索などの際にファイルの内容が変更されているか確認し、変更があれば自動で読み直します。
フォルダを指定していれば、その中のxlsxを更新・改名した場合も、`set_naaa_metadata()`の再実行は不要です。

### メタデータで分析に用いる変数を確認する

| メタデータの列名 | 定義 | 例 |
|---|---|---|
| `調査カテゴリ` | 誰を対象とした調査か | 児童 |
| `年度` | 調査年度 | H24、H25 |
| `変数` | 実データCSVにある元の列名 | 児童質問紙回答_01 |
| `ラベル_raw` | 元資料に記載された質問文・ラベル | 質問内容の確認に使用 |
| `ラベル_norm` | 修正を反映した質問文・ラベル | 検索・内容確認に使用 |
| `年度変数` | 年度と元の変数名を組み合わせた値 | H24_児童質問紙回答_01 |
| `concept_id` | 設問系列の識別子。対応表では年度間の対応キーとして使用 | C001 |
| `concept` | 設問系列の名称。対応表では作成するデータの列名として使用 | 朝食 |

`変数`に入っている日本語の列名は、そのまま読み込みに使います。

## 使い方

以下は、このパッケージを使って複数年度のcsvファイルから分析に使う項目をまとめて読み込み、データ化する方法です。
検索キーワード・年度・CSVのパスは、ご自身の作業フォルダに合わせて指定してください。

### 1. 元のCSVファイルをUTF-8へ変換する
配布されるデータがUTF-8ではなく、データの読み込みに時間がかかるため、この関数を使いUTF-8に変換可能です。

```r
convert_utf8(
  input = "raw/H24_児童.csv",
  out_dir = "utf8"
)

convert_utf8(
  input = "raw/H25_児童.csv",
  out_dir = "utf8"
)
```
元のCSVは変更せず、同じファイル名で別フォルダに保存します。

| 引数 | 内容 | 既定値 |
|---|---|---|
| `input` | 元データのCSVファイルのパス | 必須 |
| `out_dir` | 出力フォルダ。存在しなければ作成 | 必須 |
| `os` | `"auto"`・`"mac"`・`"win"` | `"auto"` |
| `overwrite` | 既存の出力ファイルを置き換えるか | `FALSE` |

ファイル全体が既にUTF-8であればそのままコピーし、
それ以外はCP932（WindowsのShift-JIS系）としてUTF-8へ変換します。
対応範囲はUTF-8とCP932です。変換できない場合はエラーになります。

macOSでは`iconv`、WindowsではPowerShellの.NET機能を使います。
必要ツールが見つからない場合、そのことを示すエラーを示して停止します。
実行環境と異なる`os`の指定はエラーとなります。

#### 複数年度をまとめて変換する

H24〜R6など複数年度をまとめてUTF-8に変換する場合は、次を実行します。
利用する調査年度を指定して実行してください。

```r
years <- c(
  paste0("H", 24:31),
  paste0("R", 3:6)
)

for (year in years) {
  convert_utf8(
    input = file.path("raw", paste0(year, "_児童.csv")),
    out_dir = "utf8"
  )
}
```

`raw/H24_児童.csv`などの12ファイルを順に変換し、同じファイル名で`utf8`へ保存します。
この例は対象のCSVがすべて`raw`にある想定です。必要なCSVがない場合や、
同名の出力ファイルが既にある場合は、そのファイルで停止します。

### 2. 調査カテゴリ・年度・変数で候補を抽出する
配布されるデータは変数が非常に多く、年度間で変数名の表記揺れ等もあるため、この関数では、調査カテゴリ・年度・使いたい変数のキーワードで分析に使用する変数のメタデータのみを抽出可能です。
アウトプットされるxlsxファイルを自身で編集し、[3. Excelで行を選び、conceptを確認・編集する](#edit-mapping)で変数指定をしてデータの読み込みに使えます。
以下は、児童のH24〜R6について、12項目の候補をまとめて抽出する例です。

```r
make_variable_mapping(
  category = "児童",
  years = "H24:R6",
  keyword = contains(c(
    "朝食",
    "寝る",
    "起きる",
    "勉強する時間",
    "読書",
    "テレビ",
    "ゲーム",
    "携帯電話",
    "国語の勉強は好き",
    "算数の勉強は好き",
    "性別",
    "学校コード"
  )),
  output = "mapping.xlsx"
)
```

この例では、作業フォルダに`mapping.xlsx`を保存します。
検索語は候補を探すためのものです。質問文が年度で変わる場合は、検索語を追加するなどして
必要な項目が含まれているか確認してください。

| 引数 | 内容 |
|---|---|
| `category` | 調査カテゴリ。`"児童"`・`"生徒"`・`"児童保護者"`・`"生徒保護者"`・`"小学校"`・`"中学校"`の6種類から1つを指定 |
| `years` | 年度。`"H24:R6"`のような範囲、または`c("H24", "H25", "R6")`のような個別年度 |
| `keyword` | 変数の検索条件。`contains()`・`matches()`などで、変数名や質問文を検索 |
| `output` | 出力するxlsxのパス |
| `overwrite` | 既存のxlsxを置き換える場合は`TRUE`。既定は`FALSE` |
| `sort_by` | 出力順。既定の`"keyword"`は検索語ごと・年度順、`"source"`は元のメタデータの行順 |

調査カテゴリと年度で絞ったメタデータの`変数`・`ラベル_raw`・`ラベル_norm`を検索します。
`select()`で使う検索ヘルパーと同じ指定方法で、部分一致や正規表現を使えます。
`contains()`・`matches()`・`starts_with()`・`ends_with()`の4種類が利用可能です。

| `keyword`の指定例 | 抽出する行 |
|---|---|
| `contains("朝食")` | 「朝食」を含む行 |
| `contains(c("朝食", "読書"))` | 「朝食」「読書」のいずれかを含む行 |
| `matches("朝食\|読書")` | 正規表現で「朝食」または「読書」に一致する行 |
| `matches("朝食.*毎日")` | 「朝食」の後に「毎日」が現れる行 |
| `starts_with("児童質問紙回答_")` | 「児童質問紙回答_」で始まる行 |
| `ends_with("時間")` | 「時間」で終わる行 |

英字の大文字小文字は既定では区別しません。区別する場合は`contains("ICT", ignore.case = FALSE)`と指定してください。
条件は`c()`でまとめることもできます。

```r
make_variable_mapping(
  category = "児童",
  years = "H24:R6",
  keyword = c(contains("朝食"), matches("寝る|起きる")),
  output = "mapping.xlsx"
)
```

出力は、指定した検索語の順に候補をまとめ、各グループ内を古い年度から順に並べます。
例えば`contains(c("朝食", "寝る", "読書"))`なら、朝食のH24〜R6、寝るのH24〜R6、読書のH24〜R6の順になります。
平成・令和をまたぐ年度も、西暦に直して並べます。同じ年度に複数の候補がある場合は、元のメタデータ内の行順を保ちます。

複数の検索語に一致する元の行は、最初に一致した検索語のグループに1回だけ出力します。
この並べ替えは、質問内容が同じと自動判定するものではありません。各候補の質問文・選択肢を見て確認してください。
`matches("寝る|起きる")`は1つの正規表現なので1グループです。別々に比較する場合は、`c(contains("寝る"), contains("起きる"))`と指定してください。
`!contains("学校")`のように除外条件だけで抽出する場合は、残った候補を年度順に並べます。
元のメタデータの行順で出力したい場合は、`sort_by = "source"`を指定してください。

`years = "H24:R6"`は両端を含む範囲です。この範囲で利用可能な年度をメタデータから抽出し、
調査のない年度は含まれません。

1つの対応表は1つの調査カテゴリを対象とします。
他の調査カテゴリを調べる場合は、調査カテゴリを変更して、別の対応表を作成してください。

xlsxには、抽出したメタデータの元の列をすべて保存し、「年度」のすぐ右に「西暦」列を追加します。
「西暦」は年度から自動計算します。例えばH24は2012、H31・R1は2019、R3は2021です。
値と列名は文字列として書き出し、`01`と`1`の区別、先頭0、ラベルの句読点などを保持します。

### 3. Excelで行を選び、conceptを確認・編集する

[2. 調査カテゴリ・年度・変数で候補を抽出する](#make-mapping)で作成した`mapping.xlsx`をExcelで開き、次の編集を行ってください。

1. 読み込まない候補行を削除する。
2. 既存の`concept_id`・`concept`を確認する。年度間で同じ列にする行には、共通の`concept_id`と`concept`を付ける。元の対応関係をそのまま使う場合は、書き換える必要はありません。

`concept_id`は年度間の対応キー、`concept`は作成するデータの列名です。
分析目的に応じて対応関係を変更する場合は、出力した対応表のこの2列を編集してください。
同じIDを使う行では、名称もそろえます。

編集後は、作業フォルダに`mapping_edited.xlsx`という名前で保存してください。

元の`調査カテゴリ`・`年度`・`変数`はメタデータとの照合に使います。
これらは書き換えないでください。
`西暦`は年度から計算した確認用の列です。

以下は、児童の暫定版メタデータから作成した対応表の一部抜粋です。
「抽出直後」は実際の対応表の値を示し、「編集後」は現在の仕様に合わせた編集例です。
調査カテゴリはすべて「児童」のため表から省略しています。
元の対応表にない「西暦」は、現行の関数が追加する列として補っています。他の列は省略しています。

#### 例1：年度間で朝食の項目を対応付ける

**抽出直後**

| 年度 | 西暦 | 変数 | concept_id | concept |
|---|---|---|---|---|
| H24 | 2012 | 児童質問紙回答_01 | P_EXACT_a3e1e255d7e607f5 | 朝食を毎日食べていますか |
| H30 | 2018 | 児童質問紙回答_007 | P_EXACT_a3e1e255d7e607f5 | 朝食を毎日食べていますか |
| R6 | 2024 | 児童質問回答_001 | P_SINGLE_c251990f131618c6 | 回答(1)/朝食を毎日食べていますか |

H24とH30は元の変数名が異なりますが、既存のIDと名称が共通なので、そのまま同じ列に読み込めます。
R6は暫定版メタデータでは別のID・名称になっています。質問文と選択肢を確認し、同じ項目として扱うかは分析者が判断してください。
ここでは3年度を同じ項目として扱うと判断し、IDを`breakfast`、名称を「朝食」にそろえる例を示します。

**編集後（太字が変更箇所）**

| 年度 | 西暦 | 変数 | concept_id | concept |
|---|---|---|---|---|
| H24 | 2012 | 児童質問紙回答_01 | **`breakfast`** | **朝食** |
| H30 | 2018 | 児童質問紙回答_007 | **`breakfast`** | **朝食** |
| R6 | 2024 | 児童質問回答_001 | **`breakfast`** | **朝食** |

この対応表で読み込むと、3年度の元変数を「朝食」という1つの列に縦結合します。
既存のIDと名称で年度間の対応関係がそろっている場合は、変更する必要はありません。
選択肢のコードや値ラベルは、同じ列にした後も元の年度の定義を保持します。
この例の選択肢の違いは、[4. 選択肢の比較](#choice-comparison)で確認します。

#### 例2：「読書」で抽出された候補から必要な行を選ぶ

H29（西暦2017年）について「読書」を含む候補を抽出すると、次の5行が出力されます。
この例は1年度だけのため、「年度」「西暦」も表から省略しています。

**抽出直後**

| 変数 | concept_id | concept |
|---|---|---|
| 児童質問紙回答_018 | P_EXACT_d59be13151888cfe | 学校の授業時間以外に,普段(月~金曜日),1日当たりどれくらいの時間,読書をしますか(教科書や参考書,漫画や雑誌は除く) |
| 児童質問紙回答_021_1 | P_SINGLE_7eb86c1cd2103448 | 児童質問紙回答_021/放課後に何をして過ごすことが多いですか-家で勉強や読書をしている |
| 児童質問紙回答_022_2 | P_SINGLE_c584f541131195e9 | 児童質問紙回答_022/土曜日の午前は,何をして過ごすことが多いですか-家で勉強や読書をしている |
| 児童質問紙回答_023_2 | P_SINGLE_7bdce87fa9ad81df | 児童質問紙回答_023/土曜日の午後は,何をして過ごすことが多いですか-家で勉強や読書をしている |
| 児童質問紙回答_072 | P_EXACT_07724c6f71c8287f | 読書は好きですか |

このうち、読書時間の項目（`児童質問紙回答_018`）と、読書が好きかを尋ねる項目（`児童質問紙回答_072`）を使う場合は、その2行だけを残します。
放課後や土曜日の過ごし方を尋ねる3行は削除します。
さらに、この例では残した項目にそれぞれ`reading_time`・「読書量」、`reading_like`・「読書好き」というIDと名称を付けます。
複数年度で同じ項目を使う場合は、他年度で残した該当行にも同じIDと名称を付けてください。

**編集後（太字が変更箇所）**

| 変数 | concept_id | concept |
|---|---|---|
| 児童質問紙回答_018 | **`reading_time`** | **読書量** |
| 児童質問紙回答_072 | **`reading_like`** | **読書好き** |

ここで残した行は、[4. xlsxを指定して読み込み、年度間で縦結合する](#read-data)ですべて対象となります。
同じ調査カテゴリ・年度・データセットに同じ`concept_id`の行が複数ある場合は、不要な候補行を削除するか、別のIDと名称を付けてください。
同じIDに異なる名称がある場合や、異なるIDに同じ名称を付けた場合、必須項目が空欄の場合もエラーになります。

#### 任意の列で対応付けたい場合

対応表に独自の列を追加した場合は、`name_col`にその列名を指定できます。
指定列の値が同じ行を同じ出力列として扱い、その値を列名にします。
この場合、対応表の`concept_id`・`concept`は対応付けに使いません。
任意の列は編集用の対応表に追加してください。

```r
data <- read_naaa_data(
  data_dir = "utf8",
  mapping = "mapping_edited.xlsx",
  name_col = "自分の変数名"
)
```

### 4. xlsxを指定して読み込み、年度間で縦結合する

UTF-8変換済みCSVと[3. Excelで行を選び、conceptを確認・編集する](#edit-mapping)で編集したxlsxファイルを用いて年度間で縦結合したデータを作成できます。
例えば、以下のようにutf8というフォルダにUTF-8変換済みCSVを置いてください。

```text
utf8/
├─ H24_児童.csv
├─ H25_児童.csv
├─ …
└─ R6_児童.csv
```

[3で編集・保存した`mapping_edited.xlsx`](#edit-mapping)を指定します。

```r
data <- read_naaa_data(
  data_dir = "utf8",
  mapping = "mapping_edited.xlsx"
)

head(data$data)
data$skipped
data$choice_comparison
```
対応表の`concept_id`に基づき、各年度の選択変数を同じ列へ縦結合します。
`name_col`を指定していなければ、出力列名は`concept`です。

| 返り値 | 内容 |
|---|---|
| `data$data` | 年度間で縦結合した分析用のデータ（`data.table`） |
| `data$skipped` | 読み込み対象から除外した年度・変数・理由（`data.frame`） |
| `data$choice_comparison` | 分析用変数ごとの年度別の選択肢比較とコード・値ラベル一覧（`data.frame`） |
| `data$sources` | `sources = TRUE`の場合のみ、読み込みに使ったCSVのデータセット・カテゴリ・年度・保存場所・内容確認用の値・レコード数（`data.frame`） |

1行は元CSVの1レコードです。年度は昇順、各CSV内の行順は元のまま読み込みます。
出力の先頭5列は、以下の年度・カテゴリ情報と元CSV内のレコード番号です。

| 列名 | 内容 | 例 |
|---|---|---|
| `dataset_id` | カテゴリコードと西暦を組み合わせたデータセットID | `pupil_2012` |
| `category_code` | 調査カテゴリを表すコード | `pupil`（児童） |
| `year_era` | メタデータにある和暦の調査年度 | `H24` |
| `year_ad` | 西暦の調査年度 | `2012` |
| `source_row` | ヘッダーを除く元CSVのレコードを1から数えた番号 | `1` |

続く列名は[3で編集・保存した`mapping_edited.xlsx`](#edit-mapping)の`concept`、または`name_col`で指定した列の値です。
`year_ad`・`source_row`は整数です。CSVから読む値は文字列で、先頭0、空文字、文字列`NA`、空白、引用符・改行、元の欠損コードを保持します。

`source_row`は同じ元CSV内の行を対応付けるための番号です。ファイルの物理的な行番号ではありません。
例えば、引用符で囲まれたセル内に改行があっても、1つのCSVレコードとして数えます。
引数`sources`の既定値は`FALSE`です。既定ではCSVの管理表を作成せず、読み込みに使うCSVファイルの内容が変更されていないかの確認も行いません。
元CSVの内容も確認したい場合は、[5の確認方法](#check-sources)のように、最初の読み込みから`sources = TRUE`を指定してください。

ある分析用変数について対応する行がない年度では、その列の値は`NA`になります。
対応表に年度自体が残っていなければ、その年度は読み込みません。

<a id="choice-comparison"></a>

#### 選択肢の比較

分析用変数ごとに、実際に読み込んだ年度のうち最も古い年度（oldest）を基準にします。
例えば、朝食をH24〜R6で読み込めばH24、H30〜R6に絞ればH30が基準になります。
そのため読み込む年度を変更すると、基準年度と「共通」「異なる」の判定が変わる場合があります。
比較には、現在指定しているメタデータの選択肢を使います。

例えば、[3の朝食の例](#edit-mapping)では、メタデータに次の違いがあります。違いを確認しやすいよう、一部のコードと値ラベルだけを抜粋しています。

| 年度 | 「その他」のコード | コード`2`の値ラベル | H24を基準とした`choice_status` |
|---|---|---|---|
| H24 | 9 | どちらかといえば，している | 共通 |
| H30 | 99 | どちらかといえば，している | 異なる |
| R6 | 99 | どちらかといえば、している | 異なる |

H30は「その他」のコードが`9`から`99`に変わり、R6はそれに加えてコード`2`の値ラベルの読点が「，」から「、」に変わっています。
この3年度を同じ「朝食」列に読み込んでも、コード`9`と`99`を自動でそろえることはありません。
列の対応付けと、回答値の再符号化は別の作業です。

比較結果は`data$choice_comparison`という表に入ります。
`analysis_name`は実際の出力列名です。既定では、編集した対応表の`concept_id`・`concept`も返します。
`name_col`で任意の列を指定した場合、この2列は`NA`になります。
`reference_variable_id`列には、各行の比較基準となった変数のIDを記録します。
その表の`choice_status`列に「共通」「異なる」「情報不足」を記録します。
`choices`列には、各行の年度・変数に対応するコードと値ラベルの一覧が入ります。
一覧は`code`・`label`という文字列の列を持つ表です。選択肢情報がない場合は0行の表になります。
編集した対応表の選択肢ではなく、現在指定しているメタデータの定義を返します。

```r
# 出力列名・年度・選択肢の比較結果を確認
data$choice_comparison

# 1行目の年度・変数に対応するコードと値ラベルを確認
data$choice_comparison$choices[[1]]

# 全年度・全変数の一覧を、1行1コードの表として確認
tidyr::unnest(data$choice_comparison, cols = choices, keep_empty = TRUE)
```

| `choice_status`列の値 | 判定 |
|---|---|
| 共通 | 定義されているコードと値ラベルの組がすべて一致 |
| 異なる | コードの追加・削除、または値ラベルに差がある |
| 情報不足 | 基準変数または比較対象に選択肢情報がない |

無回答・非該当も比較に含め、句読点・空白だけの差も「異なる」にします。
コード列の並び順は判定に影響しません。基準変数自身は、選択肢情報があれば「共通」です。
この判定は選択肢定義の一致を表し、質問内容や尺度の同等性は分析者が判断します。
回答値の自動変換は行いません。必要な再符号化は分析者が行います。

#### 読み込めない年度の扱い

既定の`on_missing = "error"`では、必要なCSVや採用した列が見つからない場合に停止します。
`on_missing = "skip_year"`を指定すると、その年度全体を除外して警告し、理由を返します。

```r
data <- read_naaa_data(
  data_dir = "utf8",
  mapping = "mapping_edited.xlsx",
  on_missing = "skip_year"
)
data$skipped
```

対応表の不正な指定、不正なCSV・文字コードは常にエラーです。
すべての対象年度が除外された場合も停止します。

<a id="add-variables"></a>

### 5. 作成済みデータに変数を追加する

[4で作成した`data`](#read-data)に、後から国語・算数の正答数を追加する例です。
まず、追加したい変数候補を別の対応表へ出力します。

```r
make_variable_mapping(
  category = "児童",
  years = "H24:R6",
  keyword = contains(c("正答数_国語", "正答数_算数")),
  output = "scores_mapping.xlsx"
)
```

`scores_mapping.xlsx`をExcelで開き、不要な候補行を削除してください。
残した国語の行には`concept_id = "japanese_score"`・`concept = "国語正答数"`、
算数の行には`concept_id = "math_score"`・`concept = "算数正答数"`を付け、
年度間で同じ列にする行のIDと名称をそろえます。
A・B問題や教科など、同じ年度に候補が複数ある場合は、読み込む項目を選んでください。
複数のテストの正答数を自動で合算することはありません。
編集後は`scores_mapping_edited.xlsx`として保存します。

```r
data <- add_naaa_variables(
  data,
  mapping = "scores_mapping_edited.xlsx",
  data_dir = "utf8"
)

head(data$data)
data$join_summary
```

第1引数には、`read_naaa_data()`の返り値であるリスト全体（上の例では`data`）を渡します。
入力オブジェクトを直接書き換えず、追加後のリストを返すので、上の例のように戻り値を代入してください。
引数`sources`は本関数でも既定で`FALSE`です。管理表がない入力には、`data_dir`または`files`で元CSVの場所を指定してください。
追加には、最初の読み込みと同じ内容・同じレコード順のCSVを使ってください。既定ではファイルの内容が変更されているかを照合せず、調査カテゴリ・年度・`source_row`の組で行を対応付け、既存の行数と行順を保ったまま列を追加するので、元のCSVファイルを変更した場合には、適切に列結合できません。

既存データにない年度の行は増やしません。既存年度に対応表の行がない項目は、追加列の値が`NA`になります。
行を対応付けるキーが重複する場合、追加列名が既存列名と重複する場合、年度・カテゴリ情報やレコード番号の範囲が不正な場合は、`sources`の設定にかかわらずエラーになります。

追加後の`data$choice_comparison`・`data$skipped`には、以前の結果と今回の追加分をまとめて返します。
`data$join_summary`は直近の追加について、データセットごとに次の件数を返します。

| 列名 | 内容 |
|---|---|
| `n_existing` | 既存データの行数 |
| `n_matched` | キーが一致して追加側の行と対応付いた既存行数 |
| `n_unmatched` | 追加側の行と対応付かなかった既存行数 |

これらはキーの照合件数です。読み込んだ回答値の欠損数を表すものではありません。
`name_col`による任意列の指定や、`on_missing = "skip_year"`による不足年度の扱いも指定できます。
既存データと追加用の対応表に共通する年度が1つもない場合や、すべての追加対象年度が除外された場合は停止します。

<a id="check-sources"></a>

#### 元CSVの内容も照合する場合

最初の読み込みと追加の両方で、引数`sources = TRUE`を指定します。

```r
data <- read_naaa_data(
  data_dir = "utf8",
  mapping = "mapping_edited.xlsx",
  sources = TRUE
)

data <- add_naaa_variables(
  data,
  mapping = "scores_mapping_edited.xlsx",
  sources = TRUE
)
```

この場合、`data$sources`に`dataset_id`・`category_code`・`year_era`・`year_ad`・`path`・`md5`・`n_records`を記録します。
読み込み中にCSVの内容が変わっていないかを確認し、追加時には、最初に読み込んだUTF-8のCSVと同じ内容・レコード数であることも確認します。
管理表に元CSVのパスが残っているため、追加時の`data_dir`・`files`は省略できます。
CSVを移動した場合は、追加時に`data_dir = "移動先のフォルダ"`、または`files`で新しいパスを指定してください。
保存場所が変わっても、内容が同じであれば照合できます。

`sources = FALSE`で作成した結果に、後から`sources = TRUE`を指定して初回のCSVを照合することはできません。
照合を利用する場合は、`read_naaa_data()`から`sources = TRUE`で読み込み直してください。
以前の版で作成し、`source_row`がない結果も、新しい版の`read_naaa_data()`で読み込み直してください。

## 変数の検索や分析用変数をRで作成する場合

`search_naaa_variables()`ではメタデータファイルから変数を検索できます。`create_naaa_concept()`は、年度間で同じ項目として扱う変数の対応関係（concept）を定義します。
`set_naaa_metadata()`でメタデータのフォルダを指定し、キーワードや正規表現で検索し、結果をR上のデータフレームとして扱えます。
検索対象は`変数`・`ラベル_raw`・`ラベル_norm`です。
[対応表作成時の検索](#make-mapping)と同じく、`contains()`で部分一致、`matches()`でメタ文字を使う正規表現、
`starts_with()`・`ends_with()`で前方・後方一致を指定できます。

```r
set_naaa_metadata("meta")

# 部分一致で検索
vars <- search_naaa_variables(contains("朝食"))

# 正規表現で検索
vars_regex <- search_naaa_variables(matches("朝食.*毎日"))

# 複数の条件をまとめて検索
vars_multiple <- search_naaa_variables(
  c(contains("朝食"), matches("寝る|起きる"))
)

selected <- dplyr::filter(
  vars,
  category_code == "pupil",
  year_era %in% c("H24", "H25")
)

# 質問文を確認し、1データセットにつき1変数を選んでから作成
breakfast <- create_naaa_concept(
  name = "朝食",
  variable_id = selected$variable_id,
  reason = "年度間で同じ項目として扱う"
)
```

`vars`は英語の項目名を持つ表で、`variable_name`が元メタデータの`変数`、`year_era`が`年度`、`category_code`が`調査カテゴリ`に対応します。
`choices`列には、各変数のコードと値ラベルを文字列の`code`・`label`列で持つ表が入ります。
`&`による条件の組み合わせや`!`による除外にも対応します。

conceptは同じカテゴリ内で、1データセットにつき1変数を選んで作成します。
`name`はconcept名です。このオブジェクトを`concepts`で渡す場合は、`concept_id`が出力列名になり、既定は`name`と同じです。
`reason`には任意の判断理由を指定できます。最初に指定した変数を基準に選択肢を比較し、
`breakfast$variables`に`variable_id`・`reason`・`year`・`choice_status`を返します。

```r
files <- c(
  pupil_2012 = "utf8/H24_児童.csv",
  pupil_2013 = "utf8/H25_児童.csv"
)

data <- read_naaa_data(
  files = files,
  concepts = list(breakfast),
  years = c("H24", "H25")
)
```

`files`の名前は検索結果の`dataset_id`と一致させます。
`concepts`と、元変数を指定する`variables`または`variable_id`は併用できます。
詳細は`?read_naaa_data`・`?create_naaa_concept`を参照してください。

`years = c("H24", "H25", "R3")`のような個別指定、
`year_range = c("H24", "R6")`のような範囲指定にも対応しますが、両者は同時に指定できません。
